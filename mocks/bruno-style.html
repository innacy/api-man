5 · What changes versus the app today

  • Layout: the request and response move side by side, with a draggable divider (they're stacked today). Narrow windows switch back to stacked.
  • Request tabs: open several requests at once, each with a dot if it has unsaved changes. Today there is one request on screen at a time.
  • Collection tree: folders inside collections, the method in a fixed-width column, right-click menus, and drag to reorder (needs a small database change for folders).
  • Top bar: Bruno's Git branch and sync controls become a Local · saved on this machine label, and the environment picker sits in the same place as Bruno's.
  • Sidebar footer: History, Environments and Load tests (Bruno puts API specs and mock servers here).
  • Status bar: settings, Appearance (mode and accent, option C above), server status, Ctrl K search, where data is stored.
  • Params table: adds a Description column and Bulk edit (paste key: value lines). Each row gets a trash icon, and the empty row at the bottom keeps today's behaviour.
  • Response: line numbers, folding, format picker, and status/time/size on the right of the tabs. Timeline replaces today's phase bars.
  • Theme: neutral greys taken from Bruno's open-source theme (#1e1e1e base, #222224 sidebar; white in light mode), keeping our fonts and accent choices. Only the layout and colour approach are borrowed; Bruno's name and logo are not used.
  • Left out (not wanted or not needed for a local app): Git, cloud sync, accounts, scripting, GraphQL/gRPC. Any of these can come later.
